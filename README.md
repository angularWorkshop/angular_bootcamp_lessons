# Angular App Shell Structure

This branch contains the completed solution for the exercise.

## Goal

Build a custom starter screen that replaces the empty app shell with a presentable layout for future lessons.

## What the solution demonstrates

- a complete starter workspace screen with hero copy and CTA
- three finished content blocks for the first app shell
- a reusable layout foundation for the next lessons in the course
