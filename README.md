# Operations platform flow

## Goal

Coordinate table state, drawer state, uploads, and realtime jobs inside one operations shell.

## What you are training

- query-like table state
- drawer draft flow
- upload queue
- realtime job feed

## Task

Finish the TODOs in the starter files.

1. filter the visible rows by the search query
2. open the drawer for the selected row
3. queue uploads for the selected row
4. connect the realtime jobs stream once

## Definition of done

- all tests pass with `npm test -- --runInBand`
- `npm run start:dev` shows a working Angular screen and a green Jest watcher
